## 初始化 macOS 工程

- 按用户确认的 Mac 桌面 Widget 目标，以 LittleComponent 当前目录为工程根目录。
- 使用 XcodeGen 创建 LittleComponent 主应用与 LittleComponentWidget 扩展，扩展实际嵌入主应用。
- 添加 SwiftUI 空状态界面、WidgetKit 时间线与小、中两种尺寸；最低支持 macOS 26。
- 添加 VS Code 的生成工程、构建与运行任务，以及简短的运行说明。
- 采用本机临时签名，主应用和扩展均启用 App Sandbox，保留 Hardened Runtime。
- 原有 6 个文件经过 SHA-256 对比，内容均未改变。

## 验证

- Debug、Release 构建通过，主应用及嵌入扩展的代码签名验证通过。
- 实际启动主应用，确认“LittleComponent / 暂无数据”正常显示。
- 在 Xcode 打开根目录的 LittleComponent.xcodeproj，运行 Widget scheme；WidgetKit Simulator 显示小、中两种尺寸，文字无截断，重新载入正常。
- 检查项目配置、生成的 plist 与 VS Code JSON；确认源码直接位于 App、Views、Widgets，没有额外的同名源码根目录。
- 已观察的 Widget 渲染环境为深色；系统浅色与真实桌面透明外观尚未验证。业务内容和正式分发签名不属于本次初始化范围。

## 木鱼球

- 按用户要求接入真实 App Intent 点击、功德与随机福缘、日期稳定随机箴言及本地 JSON 原子持久化。
- 收到外形修订后移除彩色球面、高光与小图标底板，复用官方 ChatGPT 黑白矢量图标铺满球体。
- 时钟使用系统 TimeDataSource，避免后台轮询；每日时间线提前生成未来七个本地午夜的箴言。
- Widget 使用 StaticConfiguration；没有用户配置参数，不额外引入 WidgetConfigurationIntent。主应用只提供添加说明。
- Swift 6 下将 App Intent 静态元数据设为不可变常量，并对 WidgetKit 旧回调采用只交给一个 Task 的不可变包装。
- 工程构建版本接入两个 target 的 Info.plist；Release 产物复制到用户应用程序目录，沙盒保持开启。
